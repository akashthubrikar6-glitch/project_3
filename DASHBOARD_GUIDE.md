# 📊 HTML Dashboard - Complete Guide

## Overview
Interactive web-based dashboard for visualizing test trends with real-time charts and metrics.

---

## 🚀 Quick Start

### Option 1: Open Dashboard Directly (Recommended)
```powershell
node openDashboard.js
```
Generates dashboard and opens in your default browser automatically.

### Option 2: Generate Dashboard Only
```powershell
node createDashboard.js
```
Creates `dashboard.html` in the project root.

### Option 3: Auto-Generate After Tests
```powershell
node runFullPipeline.js
```
Automatically generates dashboard at the end of the complete pipeline.

---

## 📈 Dashboard Features

### 📊 Real-Time Metrics
- **Pass Rate %** - Latest test pass percentage with trend indicator
- **Fail Rate %** - Latest test fail percentage
- **Flaky Tests** - Count of detected flaky tests
- **Average Performance** - Historical average pass rate
- **Best Performance** - Highest recorded pass rate
- **Execution Time** - Latest test run duration

### 📉 Interactive Charts (5 Total)

1. **Pass Rate Trend**
   - Line chart showing pass rate over time
   - Trends up/down with color indicators

2. **Test Results Distribution (Pie Chart)**
   - Visual split of Passed/Failed/Flaky tests
   - Based on latest run

3. **Test Results Timeline (Stacked Bar)**
   - Passed/Failed/Flaky tests across all runs
   - Easy comparison between runs

4. **Pass/Fail Rate Comparison (Dual Line)**
   - Both pass and fail rates on same chart
   - Shows inverse relationship

5. **Failed & Flaky Trend**
   - Area chart showing problem test trends
   - Helps spot increasing issues

### 📋 Complete History Table
- All test runs with details
- Columns: Date, Time, Total/Passed/Failed/Flaky, Pass%, Duration
- Color-coded (green=passed, red=failed, yellow=flaky)
- Sorted newest first

## 🎯 Key Insights from Dashboard

### What to Look For

1. **Pass Rate Stability**
   - Should be consistently high (80%+)
   - Watch for drops - indicates regression

2. **Flaky Tests Alert**
   - Any flaky tests shown?
   - Focus on fixing these first

3. **Trend Direction**
   - Is pass rate improving? 📈
   - Is it declining? 📉
   - Flat trend is acceptable

4. **Execution Time**
   - Compare durations across runs
   - Increasing time = potential performance issue

5. **Failed Tests Pattern**
   - Same tests failing repeatedly?
   - New failures?
   - Intermittent failures = flaky tests

## 🛠️ Customization

### Modify Dashboard Colors
Edit `createDashboard.js` - look for hex color codes:
- `#28a745` = Green (Pass)
- `#dc3545` = Red (Fail)
- `#ffc107` = Yellow (Flaky)
- `#667eea` to `#764ba2` = Background gradient

### Change Chart Types
In `createDashboard.js` around line 370:
```javascript
type: 'line'  // Change to 'bar', 'area', 'pie', etc.
```

### Add More Metrics
Modify `createDashboard.js` metric-card section to track additional data.

## ⚠️ Troubleshooting

| Issue | Solution |
|-------|----------|
| Dashboard is blank/empty | Run tests first: `npx cypress run` |
| Won't open in browser | Manually open `dashboard.html` |
| Out of date data | Run: `node trendAnalysis.js` then `node openDashboard.js` |
| Charts not displaying | Check browser console for errors |
| No history data | Ensure `testTrendHistory.json` exists |
